# 🎙️ What the Prompt — macOS Studio Helm & Production Suite

A broadcast-grade macOS Studio Helm & Show Runner designed to produce live episodes, trigger synchronized audio stingers, run per-segment prompt workflows, and render angst-filled kinetic commercials and teaser animations.

---

## ⚡ Quick Start
Simply open `index.html` in any browser (Safari, Chrome, Arc, Brave) on macOS or PC:
```bash
# In your terminal:
open index.html
```

---

## 🎛️ Key Features & Architecture

### 1. 🎚️ The macOS Helm (Left Sidebar & Topbar)
* **Traffic Lights & Window Frame:** Native macOS dark glass aesthetics.
* **On-Air Broadcast Engine:** Live status indicator (`STANDBY` vs `ON AIR`), active segment countdown timer, total show stopwatch, and simulated live audio VU meter.
* **Segment Navigator:** Jump directly between segments (`Space` to advance, `1-6` to jump).

### 2. 📜 Teleprompter & Live Prompt Studio (Center Stage)
* **Teleprompter View:** Adjustable font sizes, clean high-contrast readability.
* **Segment Checklists:** Click-to-complete on-air talking points.
* **Live Prompt Studio:** Execute custom prompt runners per segment with real-time co-host take generation.

### 3. 🔊 Web Audio Synthesizer Soundboard (Right Inspector)
* **Zero External Dependencies:** Every sound is synthesized natively in real-time using the Web Audio API.
  * `808 Sub Drop` (Deep cinematic sub-bass punch)
  * `Glitch Riser` (Cyber frequency sweep)
  * `Angst Strobe` (Aggressive filtered saw pulse)
  * `Mic Drop Slam` (Heavy impact transient)
  * `Airhorn Blast` (Hype triple tone)
  * `Gavel Slam` (Double-hit verdict)
  * `Tape Stop / Static` (Vinyl stop effect)

### 4. 🎬 Kinetic Angst Commercial & Teaser Animator
* **Full-Screen Dark Theater Mode:** Press `T` or click `TEASER` on the top bar.
* **Audio-Visual Glitch Sync:** Features CRT scanlines, screen shake, synchronized bass hits, and speech synthesis voiceover:
  > *"THIS. IS. THE. VOICE. She's an American beauty, an American psycho... and she just rewrote your entire production stack before breakfast. WHAT. THE. PROMPT."*

### 5. 🚀 1-Click Multi-Channel Repurposing Engine
* **TikTok / Shorts Scripts:** Auto-generated 3 vertical hooks with visual cues.
* **X / LinkedIn Threads:** 5-post breakdown ready for viral distribution.
* **Substack / Newsletter:** Markdown-formatted recap with official ID3v2 copyright stamp.

## ⌨️ Keyboard Shortcuts
* `[SPACE]` ➔ Next Beat & Fire Transition Stinger
* `[1]` – `[6]` ➔ Jump to Segment 1 through 6
* `[T]` ➔ Launch Full-Screen Angst Commercial Teaser
* `[ESC]` ➔ Exit Teaser / Modal
